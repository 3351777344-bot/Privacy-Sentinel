## 0:00–0:30 开场介绍（约 30 秒）

> 完整口播与提词见 **`介绍.md`**。此处只保留骨架：

1. **鸿蒙特色**：ArkTS 原生 + 系统 Picker / File Kit / ArkData / 相册与 Share Kit，设备侧闭环。  
2. **痛点**：分享图 / 交代码 / 点链接 / 交材料，风险常事后才发现 → 检查前置。  
3. **原则**：本地优先、联网可选；等级 + 评分 + 证据 + 建议。

然后进入演示，细节不在开场展开。

## 0:30–3:20 功能演示

### ① HarmonyOS 首页（约 15 秒）
打开手机模拟器中的 GuardianHub，展示分享前、提交前、点击前、上传前四个安全入口，并说明四个页面复用统一风险报告组件。

### ② Privacy Sentinel 隐私哨兵（约 45 秒）
在 HarmonyOS 端通过系统相册选择一张示例图片（快递单 / 聊天截图），调用检测服务。系统在原图上框出**手机号、地址、二维码、订单号、昵称**等敏感区域，并给出风险分级。随后切到 PC Web 展示完整的打码与导出效果。

- 切换「本地处理 / 联网增强」：本地用 OCR + 正则 + 二维码定位；联网可用 Qwen VL 视觉增强，失败自动回退本地。
- 选择打码范围（高风险 / 全部 / 自定义），后端用 Pillow 对**原图真实处理**，支持黑条、模糊、马赛克，导出安全分享版本。

**强调**：这不是打个马赛克预览，而是生成真正脱敏后的新图片。

### ③ Code Guardian 代码卫士（约 40 秒）
在 HarmonyOS 端通过系统文件选择器上传一个含多种源码文件和**硬编码 API Key、SQL 拼接、命令执行、敏感日志**的项目 ZIP，点击检测。

- 项目包在内存中只读扫描，不执行代码；界面展示语言分布、风险文件优先级、文件路径和命中行号。
- 单文件可切到联网增强，由 DeepSeek 做深度分析并支持**一键修复**；项目 ZIP 为保护整体源码固定本地扫描。

### ④ Link Guard 链接卫士（约 30 秒）
在 HarmonyOS 端输入一个含 `login`、`redirect`、`token` 的 URL，来源选「短信」。系统从 HTTPS、可疑参数、关键词、随机 token、仿冒域名和来源场景生成体检报告，直接告诉你**是否建议打开**。

也可上传二维码图片，系统在**本机解析**出链接自动填入——**全程不主动访问目标地址，避免 SSRF 风险**。

### ⑤ Doc Shield 提交护盾（约 20 秒）
在 HarmonyOS 端输入课程论文的提交要求，通过系统文件选择器多选材料。系统从 PDF / DOCX / TXT 中提取内容，检查**材料完整性、格式规范、命名规则和隐私信息**，给出提交建议。

## 3:20–4:00 技术实现（约 40 秒，演示后一句带过）

- HarmonyOS 6 + ArkTS；PC：React + FastAPI。
- 本地：OCR / 二维码 / 规则引擎 / 打码；可选 Qwen、DeepSeek，失败回退本地。
- 本地 SQLite 历史；上传校验与自动清理。

---

## 4:00–4:40 创新点（约 40 秒）

1. **平台化**：四类风险进一个安全中心，不是单点工具。
2. **本地优先、联网可选**：默认可离线；增强是加分项，失败自动回退。
3. **统一可解释闭环**：等级 + 评分 + 证据 + 建议，人能看懂、能决策。
