# 鸿蒙能力说明

GuardianHub 注册系统分享目标 ShareCheckAbility。用户选择本应用后，按内容类型进入 ShareCheckPage；应用不能替代操作系统拦截其他应用的全部分享。

图片默认仅端侧二维码解析；付款码、登录或身份凭证二维码识别为敏感内容，禁止原图增强上传。图片文字 OCR 在后端执行，必须主动点击增强分析并确认。解析无结果不表示无隐私风险，界面会说明文字内容未覆盖。

代码片段默认端侧规则，ZIP 默认端侧结构和威胁扫描。增强代码或 ZIP 分析会发送原内容到配置后端，上传前提示数据类型、数量和字节大小。扫描不等同完整依赖分析或代码审计。

链接端侧静态分析，不访问目标、不查询实际跳转；显示未覆盖的信誉能力。文档本地检查结构、宏、危险脚本、压缩包和命名规则；完整材料清单和文本检查属于授权后端增强。

分享日志仅记录计数和是否有文本，不记录 Want、URI 或原文。历史是本机存储，但并非加密安全保管库，不应用于持久存储秘密。

多文件分享当前仅扫描第一个并提示；文档页可多选检查。真实图库分享、拒绝授权、断网、重复分享、未知扩展名和大文件仍需在真机完成回归。本次仅完成编译、端侧逻辑测试和静态契约检查，不冒充设备验收。
