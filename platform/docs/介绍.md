## 一、口播稿（约 30 秒，直接念）

各位老师好，我们是 **GuardianHub 数字安全防护平台**，主端跑在 **HarmonyOS** 上。

**鸿蒙特色**：不是套壳网页，而是 **ArkTS 原生应用**——用系统文件 / 相册选择器取图取包，**File Kit 受限读取**保护隐私，检测历史落在本机 **ArkData**，脱敏图可走系统相册和 **Share Kit** 分享，形成设备侧闭环。

**场景痛点**：同学分享图片、提交代码、点链接、交材料时，风险常事后才发现。我们把检查**前置**到这四个动作之前，做成统一的操作前安全中心。

**原则**：**本地优先、联网可选**；统一给出等级、评分、证据和建议。接下来直接演示。

## 三、鸿蒙特色（开场必提，演示时点到）

GuardianHub 鸿蒙端定位：**设备侧可闭环的操作前安全闸门**。

| 能力 | 开场怎么说 | 演示落点 |
| --- | --- | --- |
| ArkTS Stage 原生客户端 | 真机入口，不是 WebView | 打开首页四入口 |
| 系统 Picker（文件 / 相册） | 选图、选 ZIP、多选材料走系统能力 | Privacy / Code / Doc |
| File Kit 受限读取 | 只读授权 URI，不越权翻盘 | 上传链路 |
| Network Kit | 连私有检测服务（模拟器 `10.0.2.2`） | 四模块请求 |
| ArkData Preferences | 历史、评分、待复核本机可回看 | 首页统计 |
| 相册保存 + Share Kit | 脱敏后可落盘、可系统分享 | Privacy 闭环 |

可选扩展（开场不讲）：Scan Kit、分布式多端。

---

## 四、产品一句话 + 四模块

**一句话**：把高校高频风险动作，收敛成手机上的「操作前安全中心」。

| 节点 | 模块 | 演示只露一句 |
| --- | --- | --- |
| 分享前 | Privacy Sentinel 隐私哨兵 | 识敏感区 → 真实打码 → 保存 / 分享 |
| 提交前 | Code Guardian 代码卫士 | ZIP 内存只读扫描；片段可 DeepSeek 增强 |
| 点击前 | Link Guard 链接卫士 | 静态体检，不访问目标地址 |
| 上传前 | Doc Shield 提交护盾 | 对照要求查完整、格式、隐私 |

统一输出：`high / medium / low` + **0–100 分** + **证据** + **建议**。

---

## 五、设计原则（开场收束用）

1. **鸿蒙系统能力闭环**：选文件 → 受限读 → 检测解释 → 处置 → 落盘 / 分享。  
2. **本地优先、联网可选**：默认可离线；Qwen / DeepSeek 是增强，失败回退本地。  
3. **可解释、可闭环**：同一套报告，人能看懂、能决策。
