# GuardianHub 项目介绍

用户在收到二维码、陌生链接、代码包和文档时，常常需要在打开或转发前判断风险。GuardianHub 将轻量安全预检放进 HarmonyOS 分享菜单，让用户先查看风险原因，再决定是否继续分享。

核心流程是系统分享接收、端侧预处理、静态规则检测、风险解释和用户决策。图片可在端侧解析二维码，代码检查危险 API 和硬编码凭据，文件扫描覆盖宏、脚本、压缩包结构及敏感内容，链接执行静态规则。结果显示证据与建议，不能替代专业安全审计。

隐私边界由实际调用路径控制：默认不发送分享原内容；可选增强需要逐次授权；付款和登录凭证二维码禁止原图增强。Web 为后端分析演示端，上传前确认，不宣称浏览器离线检测。

工程创新在于原生分享入口、跨类型风险流程、端侧静态扫描组合和解释式决策，而非声称创造了新的恶意软件检测算法。生产情报源尚未接入，内置测试规则不代表真实威胁覆盖率。

当前完成可构建未签名 HAP、后端和前端测试及端侧样本验证。正式签名、真实设备回归、生产服务、原创权属确认和视频材料仍是提交前条件。近期产品化先完成这些条件，再评估依赖漏洞分析、误报反馈和组织策略。
