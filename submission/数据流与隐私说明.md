# 数据流与隐私说明

系统分享 → ShareCheckAbility → 端侧二维码与规则或文件扫描 → 风险解释 → 用户选择。

默认路径不上传原内容。用户点击增强分析后，弹窗说明后端地址、原文件或文本及数量大小，拒绝则保留本地结果；同意后发送一次请求，网络失败不自动重试。模型增强还可能发送给已配置的第三方模型。

敏感二维码识别为付款、登录或身份凭证时禁止原图增强。二维码识别可能漏检，故始终保留文字隐私未覆盖提示。文档信誉只发送哈希和风险等级，不发送文件名和抽取的 URL。

Web 所有分析 POST 要求逐次确认，但历史列表 GET 仍访问配置后端。后端存在上传和历史留存，不应将授权分析描述为无留存服务。正式部署前应审核保存时间、鉴权和删除策略。
