# 调试构建说明

HAP（`*.hap`）已被 `.gitignore` 忽略，因此本目录不存放二进制产物；此前的 `SHA256SUMS.txt` 记录了一份并不存在于仓库的 HAP，已删除，避免出现无法复算的校验和。

出包后由出包人执行 `python tools/release-check.py --write <HAP 路径>` 生成 `SHA256SUMS.txt`，内容来自磁盘上的真实产物。`tools/release-check.py` 会在清单存在时逐条核验：产物必须能找到、SHA-256 必须一致、`submission/release/` 下不得出现既非清单条目也非说明文档的跟踪文件。CI 每个 PR 都会运行该校验。

未签名调试 HAP 不适合作为正式签名参赛包；该清单只证明产物完整性，不证明发布签名或真机可安装性。

发布前必须配置轮换后的签名、实际可达的 HTTPS 后端并重新构建，随后重新运行真机回归、重新生成清单并更新所有截图与视频。
